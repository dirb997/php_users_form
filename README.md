# Form used to submit information and display the registered users on the screen
Used basic php syntax, bootstrap, javascript and simple css styling.

# Features:
1. Input validation. ☑️
2. Creation of a database for the registered users. ☑️
3. Age, password and mail validation (age requirements, mail format,...). ☑️
4. Flag (or an alert) to show if the form has been correctly submitted or if the submission failed. ☑️
5. CSS styled form (with Bootstrap 5).☑️
6. Blocked users table.☑️
7. Login page and Dashboard page.☑️
8. Validation to check if the user email and password do exist in the database.☑️ 
9. Redirection functionality to a specialized dashboard page based on the id user id. ☑️
10. Logout functionality so when we click the logout button, we are redirected to the login page. ☑️
11. In the dashboard, Edit account information functionality.☑️
    * We only can edit the following information: Name, Address, Password and Mail. 
12. Delete account's information functionality (check the logic).☑️
13. Router file.☑️
14. Controllers.☑️
15. View templates.☑️
16. Validation to check if the email address is already in the DB. If it is, display an error alert.☑️
17. Input validation for the password so it shows that it must be at least 8 characters long.☑️
18. Sign up confirmation by email functionality.☑️
19. Dockerize the project ☑️
